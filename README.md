## 🚀 Key Web Experiences

### 1. 💼 Portfolio Hub (`index.html`)
A high-performance portfolio showcasing selected work, technical skills, professional history, and educational highlights.
* **Tech Stack:** Vanilla HTML5, CSS3, Modern ES6 Javascript.
* **Aesthetics:** Dark-mode grid alignment (Bento-style layout), smooth intersection observers for fade-in animations, dynamic ambient glows, and responsive styling.

### 2. 🤖 Flutter & AI for MVP Development Slide Deck (`flutter-ai-mvp.html`)
An interactive, high-fidelity slide deck presenting **"Build Smarter, Ship Faster: Flutter & AI for MVP Development"** for **DevConnect 2026**.
* **Direct Link:** [developeryatin.github.io/flutter-ai-mvp.html](https://developeryatin.github.io/flutter-ai-mvp.html)
* **Highlights:**
  * **Interactive Theme Toggle:** Real-time adaptation for dark and light modes.
  * **Visual Flow Components:** Comparative layout of "Entrepreneur's Burden vs. Developer's Reality" (Slide 3) and framework value columns (Slide 4).
  * **Animated CI/CD Pipeline:** A horizontal pipeline simulator (Slide 10) representing a modern automated review cycle.

### 3. 🛡️ Code Review & Security Analysis with Gemini CLI (`gemini-cli.html`)
An interactive slide deck presenting advanced automation workflows using Gemini CLI to scan git commits, catch vulnerabilities, and automate code feedback.
* **Direct Link:** [developeryatin.github.io/gemini-cli.html](https://developeryatin.github.io/gemini-cli.html)

### 4. 🧠 Building Autonomous AI Agents with ADK (`data_analyst_agent.html`)
An interactive, high-fidelity slide deck introducing Google's **Agent Development Kit (ADK)** for building autonomous developer agents.
* **Direct Link:** [developeryatin.github.io/data_analyst_agent.html](https://developeryatin.github.io/data_analyst_agent.html)
* **Highlights:**
  * **Interactive Code Playgrounds:** Walkthrough of configuring real-time agent memory, agent capabilities, and LLM reasoning loops.
  * **Tool Integration:** Demonstrates using Python 3.12+, `uv`, and `google-adk` to construct production-ready tools and workflows.
  * **Premium Theme:** High-fidelity dark presentation design tailored for developers.

## 🛠️ Local Development & Preview

No complex build setups are required. You can host the site locally using any standard static file server:

### Python 3 Simple Server
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

### Node.js (Live Server)
```bash
npx live-server
```
